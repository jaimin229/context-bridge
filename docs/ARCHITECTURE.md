## packages/core

Pure TypeScript, no Electron imports. Built twice for two consumers:

- **Source barrel** (`src/index.ts`) — type-only imports in the renderer and
  the Vitest alias; the renderer never loads core at runtime because core
  pulls in `better-sqlite3` (enforced by review; `main`/`types` point at dist).
- **Built CJS dist** (`dist/` via `tsconfig.build.json`) — runtime dependency
  of the Electron main process, packaged into the asar.

Contents: migration runner + `001_initial.sql`, Zod schemas and types
(`AppResult`/`ok`/`err`), repositories (projects, capsules, tags, revisions,
settings, Active Handoff), handoff generator, JSON/Markdown export + import,
FTS5 search, secret scanner, Git capture/drift, token estimator.

## apps/desktop

### Process model

```text
┌──────────────────────────── Electron main ────────────────────────────┐
│ main.ts                                                               │
│  - opens SQLite (userData/contextbridge.db or CONTEXTBRIDGE_DATA_DIR) │
│  - runs migrations before any window is created (failure = dialog)    │
│  - secure BrowserWindow (contextIsolation, no nodeIntegration,        │
│    sandbox)                                                           │
│  - deny will-navigate, window.open, permission requests, webview      │
│  - CSP via onHeadersReceived                                          │
│  - ipc.ts: 33 Zod-validated channels → AppResult<T, AppError>         │
│    (trusted-sender check, exception containment, one shared DB)       │
│  - smoke.ts: SQLite + FTS5 probe (--smoke-test)                       │
└──────────────▲────────────────────────────────────────────────────────┘
               │ typed channels (contextbridge:projects.*, capsules.*,
               │ tags.*, revisions.*, search.*, handoff.*, git.*,
               │ secrets.*, settings.*, export.*, import.*, clipboard.*)
┌──────────────┴─── preload.ts (sandboxed, CommonJS) ───────────────────┐
│ contextBridge.exposeInMainWorld('contextBridgeApi', { projects,       │
│ capsules, tags, revisions, search, handoff, git, secrets, settings,   │
│ export, import, clipboard, ping }) — fixed named methods only.        │
│ No generic invoke(channel, payload) is exposed.                       │
└──────────────▲────────────────────────────────────────────────────────┘
               │ window.contextBridgeApi.* (src/api.ts unwraps AppResult)
┌──────────────┴─── renderer (React + Vite + Tailwind) ─────────────────┐
│ App.tsx            workspace shell, sidebar, toasts with Undo         │
│ Onboarding         first-run project creation                         │
│ CapsuleEditor      Simple/Advanced fields, save + secret-scan dialog, │
│                    exports, revision history, git capture, drift      │
│                    banner (auto-checked on open), delete confirm      │
│ HandoffPreview     debounced live handoff + token estimate            │
│ MarkdownView       structural markdown parser (no raw HTML sinks)     │
│ SearchPanel        FTS query + filters + highlighted snippets         │
│ SettingsDialog     token budget, compact mode, startup checks         │
│ ImportDialog       JSON/Markdown file picker or paste                 │
│ No node access, no raw IPC, no dangerouslySetInnerHTML.               │
└───────────────────────────────────────────────────────────────────────┘
```

Contract tests lock the seams: `tests/ipc-contract.test.ts` asserts the
preload literal channel set equals `IPC_CHANNELS` and that renderer mirror
constants equal core values; `tests/ipc-routing.test.ts` drives 20 scenarios
through `routeIpc` against a real temp SQLite database and real git repos.

### Build pipeline

- `tsc -p packages/core/tsconfig.build.json` → `packages/core/dist/`
  (runs automatically before root `typecheck`/`build`/`dev`).
- `tsc -p apps/desktop/tsconfig.electron.json` → `dist-electron/`, then
  `scripts/copy-migrations.mjs` copies `packages/core/migrations/*.sql`
  next to the compiled main (`dist-electron/migrations`, resolved via
  `__dirname`).
- `vite build` → `dist/` (renderer bundle + CSP-injected index.html).
- `electron-builder --dir` → `release/win-unpacked/` (unpacked build);
  `electron-builder --win nsis` → `release/ContextBridge Setup <v>.exe`.
  Both use `build/icon.ico` (regenerate with `node scripts/make-icon.mjs`).

### Data storage

SQLite (`contextbridge.db`) under Electron `userData`, or under
`CONTEXTBRIDGE_DATA_DIR` when set (used by every E2E launch for isolation).
Pragmas: `foreign_keys = ON`, `journal_mode = WAL`, `busy_timeout = 5000`.
Migrations run at startup with a `VACUUM INTO` backup before pending files.
Tables: projects, capsules (CHECK enums), tags, capsule_tags,
capsule_revisions, app_settings, `capsules_fts` (external-content FTS5 with
triggers).

### Dev vs packaged content loading

- Dev: main loads `CONTEXTBRIDGE_DEV_SERVER` (Vite) when the env var is set.
- Packaged/production: main loads `file://` `dist/index.html` from the asar.
- Remote content is never loaded.
